# 这张 2 美元的亚马逊优惠券扭转了销售下滑——看看 Happy Start 是怎么做的

This $2 Amazon coupon reversed a sales dip — here's what Happy Start did

您好，我是 The Happy Start 的 Jerry。作为小企业主，最令人沮丧的感受之一，就是明知道自己的商品很出色，却只能看着它无人问津，被埋没在搜索结果中。今天，我想和您聊聊优惠券和促销如何帮助我们脱颖而出。

亚马逊提供多种促销工具，其中对我们最有效的工具之一就是优惠券。操作很简单。您设置一个折扣，比如减免 5% 或减免 2 美元，买家在购买前点击一个小方框，就能领取优惠券。

过去，我们主要将促销优惠券用于三个方面：新品发布、提振低迷的销售，以及节假日。例如，几个月前，我们发现销量突然下滑，但并没有惊慌。相反，我们启用了一张简单的减免 2 美元优惠券，这项促销让我们在其他所有商品信息中脱颖而出。

我们的点击率几乎立刻就大幅提升，销售速度最终也恢复了。简而言之，优惠券能够让正在滚动浏览的买家停下来，并吸引他们的目光，而普通的价格标签却做不到这一点。这里有一个专业小技巧。

了解买家的心理。如果您的商品价格低于 20 美元，请使用百分比折扣促销，而不是固定金额折扣。这会让买家觉得优惠力度更大。

如果商品价格高于 20 美元，请使用固定金额折扣，因为买家会觉得这是真正留在自己口袋里的现金。但请小心。您可不想意外叠加折扣，否则最终可能相当于免费送出商品。

明智地使用优惠券和促销，看着您的销量增长。
