# Set order-handling capacity

欢迎观看本期《关于如何设置订单处理容量》的培训视频。
在本视频中,我们将向您展示如何为在默认处理时间内所需处理的订单数量设置限制。
通过使用订单处理容量、Order Handling Capacity 功能,您可以额外获得一天的时间来处理超出已设置容量的订单。
此功能可帮助您管理订单负荷,并保护您的账户状况。
亚马逊商店中的报价都附带买家配送承诺Customer Delivery Promise,
该承诺代表订单预计送达的日期范围。
当买家配送承诺中的日期接近买家看到报价的时间时,您的报价更具吸引力。
但是,如果您的订单数量超出一天之内的备货能力,则可能很难按时将包裹发送给买家。
买家需要能够信任买家配送承诺,延迟配送会影响您的账户状况。
那么,如何在缩短配送时间的同时确保账户状况?
我们有工具来帮助您做到这一点。
假设您设置了一天的默认处理时间,以便更快地将购买的商品交到买家手中。
不过您担心,如果订单数量突然激增该怎么办?
有时候可以预见峰值即将到来,例如在假期前后。
此外,还会有突然出现的其他峰值,比如您的品牌突然出乎意料地流行起来。
一些卖家可能担心收到的订单数量超出了他们的配送能力,无法在处理时间内发货,进而致使他们的账户状况遭受影响。
您无需延长默认处理时间来适应潜在的订购高峰。
相反,您可以设置订单处理容量。
订单处理容量对您在默认处理时间内可以配送的订单数量设置限制。
如果您的默认处理时间为一天,并且收到的订单数量已超过订单处理容量。
亚马逊将自动增加一天的处理时间,并将所有额外订单的处理时间设置为两天。
请注意,这些订单将计入您第二天的限额。
因此,如果您的订单容量为100个订单,而您获得120个订单,则多出的20个订单将计入第二天的订单容量。
这样,您拥有的订单将永远不会超出您的处理能力,可以保护您的账户状况。
您可以在设置默认处理时间的位置设置订单处理容量。
访问卖家平台主页,通过选择右上角的齿轮图标,打开设置菜单。
选择配送设置,Shipping Settings。
然后在下一个屏幕上,选择常规配送设置,General Shipping Settings。
之后向下滑动页面,找到备货时间,Handling Time。
在设置默认备货时间的同一区域，可以看到订单处理容量。
Order Handling Capacity。
单击右侧的编辑,Edit。
在下一个屏幕的底部,找到订单处理容量。
Order Handling Capacity。
在这里可以输入容量,然后选择下面的保存,Save。
请注意,订单处理容量,仅影响处理时间在零到两天之间的非Prime订单。
如果您为特定 ASIN 设置的备货时间超过两天，该 ASIN 的订单将不会进入您的处理能力。
准确的买家配送承诺,Customer Delivery Promise,是成为成功卖家的重要组成部分。
订单处理容量,可以帮助您缩短备货时间。
同时,在订单突然激增时,保护您的账户状况。
这对卖家和买家来说,都是好消息。
我们的订单处理容量培训到此结束。
感谢观看,祝您销售愉快。
