# Intro to Brand Analytics

欢迎观看本期《品牌分析/简介》培训视频。
在亚马逊品牌注册中注册的品牌,可以享受一系列额外的销售权益。
其中一项权益是可以使用一组称为品牌分析的报告。
品牌分析报告,提供汇总的产品和买家信息,以及竞争洞察信息。
可以凭借这些信息来更好地了解品牌在亚马逊商店中的表现,
并根据数据做出有关商品和广告的战略决策。
如果您是已在品牌注册中注册的品牌的内部卖家,
那么您可以随时访问品牌分析。
操作非常简单,只需在卖家平台的主菜单中选择品牌:Brands,
然后点击品牌分析:Brand Analytics,
或者点击创立您的品牌:Build Your Brand,
然后找到品牌分析:Brand Analytics卡。
有关访问品牌分析和其他品牌注册工具的更多信息,
请参与卖家大学中关于请求获得或管理品牌销售权益的模块。
访问品牌分析工具后,您将在屏幕顶部看到每个报告的对应选项卡。
下面,我们来快速看一下每个报告中的指标,
以及这些指标可以如何帮助您提升品牌绩效。
您可以使用目录搜索表现,Search Catalog Performance报告,
了解买家在搜索亚马逊商店后如何与您的商品互动。
该报告列出了您品牌下的各种商品,
并将它们与代表整个购物漏斗中买家活动的一系列指标配对。
这些指标包括展示次数、点击量、添加到购物车的次数和购买次数。
连同该报告中的其他信息,
这些指标可以帮助您了解您的商品的买家流失点。
它们还可以帮助您确定曝光率或销售转化率方面的差距。
您可以使用查询搜索表现,Search Query Performance报告,
查看买家如何在亚马逊商店中搜索您的品牌。
该报告列出了与您品牌下的商品相关的主要买家查询。
它将这些查询与一系列指标配对,
包括查询量、展示量、点击量、添加到购物车的次数和购买次数。
也可以使用ASIN 视图,
ASIN View,
显示单个商品的类似信息。
两种视图都可以帮助您了解买家是如何发现您的商品的。
或者,
还可以帮助您识别趋势和机会,
助力您扩大商品目录。
您可以使用重复购买行为,
Repeat Purchase Behavior报告,
来了解买家多次购买您的商品的频率。
该报告根据收到的订单总数列出您的每个品牌。
它将它们与重复购买相关销售额,
已订购商品数量和回头客买家数量配对。
您可以使用ASIN 视图,
ASIN View,
在商品级别找到类似信息。
两种视图都可以帮助您更好地了解您品牌的买家互动。
它们还可以帮助您评估对您的商品的满意度。
您可以使用受众特征,
Demographics报告,
获取按买家年龄、
收入、
教育程度、
性别和婚姻状况细分的品牌销售额明细。
该报告将这些类别中的每一个划分为多个段,
然后列出唯一买家数量,
以及已订购商品数量。
报告中的这些信息和其他信息,
可以帮助您更好地了解谁在购买您的商品。
这些信息还可以帮助您定义广告策略。
热门搜索词,
Top Search Terms 报告,
为品牌提供了买家搜索活动的广阔视图。
热门搜索词,
Top Search Terms 报告,
不像目录搜索表现,
Search Catalog Performance 报告,
和查询搜索表现,
Search Query Performance 报告那样,
只专注于您的品牌。
它会列出买家在亚马逊商店中查找和购买时使用的关键词。
它将每个关键词与买家搜索中点击次数最多的三个商品,
类别和品牌配对。
报告中的这些信息和其他信息可以为您提供建议,
帮助您更新与您品牌的商品详情页面相关的关键词。
这些信息也可以帮助您识别购买趋势和广告机会。
最后,您可以使用市场购物篮分析,
Market Basket Analysis 报告,
查看买家在购买您品牌下的商品时同时购买的其他商品。
该报告列出了您品牌下的各种商品,
并将它们与最常同时购买的三种商品配对。
这三种商品可以是您品牌下的商品,
也可以是竞争对手的商品。
报告中的这些信息和其他信息可以帮助您识别捆绑品牌商品的机会。
这些信息还可以帮助您评估交叉营销机会。
品牌分析工具中的每个报告都可以使用顶部的下拉菜单进行过滤,
或使用特定的列选择进行自定义。
有关如何计算,
特定指标的更多信息,
请查看指标词汇表。
您也可以下载任何品牌分析报告的副本,
以备存档或执行其他计算。
以上就是本期品牌分析简介培训视频的全部内容。
如果您想了解使用前面介绍的一个或多个报告的分步说明,
请参阅卖家大学中的品牌分析系列模块。

感谢观看,祝您销售愉快。
