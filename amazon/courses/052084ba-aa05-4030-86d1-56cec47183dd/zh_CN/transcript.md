# Set one-day default handling time

欢迎观看本期关于如何将备货时间设置为一天的培训视频。
在本视频中,我们将向您展示如何通过将默认备货时间从两天更改为一天,从而在卖家配送承诺、customer delivery promise方面进行提升。
为什么备货时间如此重要?
备货时间是赢得买家信任的关键。
亚马逊商店中的报价都附带买家配送承诺,customer delivery promise,
该承诺代表订单预计送达的日期范围。
买家配送承诺,customer delivery promise由以下因素组成,
备货时间即卖家准备和配送订单所需的天数,
运输时间即所选的承运人配送包裹所需的天数,
以及预留的缓冲时间,
用于应对承运人侧出现配送问题或天气因素的影响,
以免您无法满足配送承诺。
买家必须要在买家配送承诺,customer delivery promise的最后日期之前收到订单,
这一点非常重要。
如果商品未能按时送达,买家会怀疑您准时送达商品的能力,
同时也会对您的账户状况造成影响。
买家在亚马逊商店中看到两个价格相同,
但买家配送承诺,customer delivery promise不同的商品时,
他们更有可能会选择配送时间最短的那一个。
因此,尽可能提供最准确的备货时间是最大程度符合您的利益的。
2019年的一项研究发现,
美国的卖家自配送商品卖家会将国内订单备货时间平均高估53%,
这就意味着他们的买家配送承诺,customer delivery promise,
其实比实际配送时间长,由此导致错失了一些商机。
如果您可以更快地准备订单,缩短备货时间,
您的商品对买家将更具有吸引力。
您可考虑将默认备货时间改为一天。
请注意,一天并不意味着当日。
一天的备货时间是指订单在下一个工作日结束前完成准备并发货。
您也可以为每个ASIN单独设置备货时间。
但是,如果您可以在一天之内为大部分订单完成备货,
那么最好是更改默认备货时间。
要设置默认备货时间,前往卖家平台主页,
并通过选择右上角的齿轮图标,打开设置菜单。
选择配送设置,shipping settings。
然后在接下来的页面选择,常规配送设置,general shipping settings。
之后向下滑动页面,找到备货时间,handling time。
如果您在创建账户后,从未更改过此项,
该时间将默认被设置为两天。
选择右侧的编辑,edit。
在选择默认时间,choose your default handling time下,选中一天,one day,前面的圆圈。
然后选择保存,Save。
新的备货时间最多可能需要30分钟才能生效,并体现在配送承诺中。
重新设置默认备货时间,意味着调整每个ASIN的买家配送承诺,Customer Delivery Promise。
因此,我们只允许每24小时更改一次备货时间。
如果您认为自己可以在一天之内处理完大部分订单,
但担心某些时候收到订单数量超出您的处理能力,
或者目录中有需要特别注意的商品,
我们对这类问题也有解决方案。
您可以使用订单处理容量,order handling capacity,
来为一天内可配送的订单数量设置限制。
如果某些商品的包装时间比其他商品长,
您还可以为这些ASIN单独设置备货时间。
有关设置订单处理容量,order handling capacity,
和单独为ASIN设置备货时间的更多信息,
可观看我们其他的培训视频,
或在亚马逊卖家平台的帮助Help页面上进行搜索。
请记住,准确的买家配送承诺,
Customer Delivery Promise,
是成为成功卖家的重要组成部分,
买家更倾向于购买配送时间较短的商品。
所以,如果您能在一天内处理好订单,
将默认备货时间设置为一天,
可以让您的商品更具吸引力。
以上就是关于本期如何将默认备货时间设置为一天的培训视频。
