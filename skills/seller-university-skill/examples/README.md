# 使用示例

以下是请求写法与回答范围示例，不是课程题库或经过统计验证的效果承诺。

| 你可以这样问 | Skill 应怎样处理 |
| --- | --- |
| Sessions 和 Page views 有什么区别？ | 定位业务报告课程，解释概念并给阅读页，不先索要店铺数据 |
| 美国站 FBA 库存积压，清仓还是继续投广告？ | 先了解库龄、数量、毛利和近期销量，再形成可比较方案；不凭空决定预算 |
| 商品推广能设总预算吗？ | 区分 SP / SB，核对当前官方预算说明；不能拿旧课程给今天的确定结论 |
| 帮我处理上架错误码 | 询问错误原文、站点、商品身份和已有操作，引用相关课程给排查步骤 |
| 按 Shopify 政策帮我判断 | 明确本版只覆盖 Amazon，不套用 Amazon 规则 |

可以追加：“简短一点”“展开成 SOP”“先列还缺哪些数据”。本地检索只读随包目录；真实账号数据由你按任务明确提供。
