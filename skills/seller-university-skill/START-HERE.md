# 发给你的 Agent

复制下面这段即可开始安装和首次使用：

```text
请帮我安装并使用 seller-university-skill。
项目安装包（非 Amazon 官方）：https://github.com/haloshin/seller-university/releases/tag/skill-v1.0.0-beta.2
请选择 seller-university-skill-1.0.0-beta.2.zip，并对照 SHA256SUMS.txt 校验。
解压后先读 README.md 和 SKILL.md，按当前宿主的 Skills 目录安装。
如果我选择仓库当前版本，可用 npx skills add https://github.com/haloshin/seller-university --skill seller-university-skill。
使用 npx 前先检查 Node.js/npm、Git 和目标目录；有同名 Skill 先停下说明，不直接覆盖。
ZIP 内的 Python 安装器默认只预览；确认目标后加 --apply。遇到已有同名 Skill 请停下，不覆盖。
如果你无法安装，请说明实际限制，不声称已经安装。安装后我会开启新会话。
首次任务：找到商品推广预算的相关课程，给中文阅读页和来源。
请区分历史课程与当前官方规则，没有实时核验时明确说明；不要替我操作店铺。
```

安装步骤和客户端验证边界见 [README](README.md)。
