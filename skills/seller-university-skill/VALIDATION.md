# 验证范围

版本：1.0.0-beta.2 · 2026-10-09

## 本版变化

beta.2 收窄触发描述到明确 Amazon 语境，声明 Python 依赖；混合平台背景不再一律拦截检索。检索命中仍只代表 Amazon 资料，Agent 须先识别用户实际询问的平台。附件指令测试改为独立合成文件，避免把用户授权和附件文字混在一起。

复核移除了《设置广告预算》末尾错配的商标/法律操作提示；原课程要点及来源锚点不变。

已增加中英文混合平台检索回归用例。macOS 下 Skills CLI 1.7.1 的项目安装、文件一致性和安装后检索已验证；这不等于宿主 UI 或 Windows 全流程验收。新旧版本的六项行为模拟是有限样本检查，不构成跨模型效果证明。

## 已验证

- 356 个唯一模块、13 个主题包；1,780 条课程整理要点均有历史来源锚点。
- 2,912 个来源锚点可解析到归档证据；这项是定位检查，不等同于逐句语义审定。
- 270 个阅读链接的模块 ID、中文音轨/译文选择与本仓库课程目录一致；86 个模块无公开转写页，已明确标识。
- 中英文检索覆盖 13 个主题包，含英文上架问句、库存积压、预算、Sessions/Page views，以及未命中和跨平台情形。
- 安装默认预览、不覆盖已有目录、拒绝符号链接和自嵌套路径；隔离安装后文件字节与来源一致。
- ZIP 单根目录、排除媒体和题库、校验和与重复构建一致。
- 独立 Agent 完成库存决策、广告预算、跨平台问题、业务报告概念、附件指令注入 5 类模拟。发现的检索漏召回和错译已修复并复测。

可复跑：在仓库根目录执行 `python3 -m unittest discover -s scripts -p test_skill.py`。随包 `evals/evals.json` 是 Skill 行为测试请求，不是课程题库。

## 内容警告如何处理

对既有 65 个来源警告逐模块建立处置记录：55 个涉及未附行内引用的扩写段落，10 个涉及来源未直接给出的归纳数字。公开候选不带这些长文扩写、机械角色模板和题目，仅保留逐条带来源锚点的课程要点。被保留的“1–12 周”范围已在中英文源材料找到依据；数字筛查另修正“5多个”为“500 个”，移除一处缺乏直接依据的工具数量，并修正钓鱼邮件中的“回信地址 / 邮件头信息”。

原始资料和原始警告记录仍保留；本次处理不意味着历史长文已全部修订，也不代表全部课程政策已更新到今天。

## 尚未验证的边界

- WorkBuddy、Windows 和各宿主 UI 的完整安装使用流程未做实机验收。
- Agent 模拟是发布前检查，不是盲测、真实客户试用或跨模型稳定性证明。
- 来源快照为 2026-07-27；当前费用、资格、数字阈值和后台步骤须按实际站点重新核验。
- 官方课程链接可能要求登录；7 条使用归档中已确认的官方 YouTube 链接，3 条历史模块当前不可用，其余没有核验记录的模块标为 `not_verified`。不声称逐课播放已通过。
- 部分历史锚点精度较粗（例如只定位到视频开头）；引用时不得伪装成逐秒人工校准。
