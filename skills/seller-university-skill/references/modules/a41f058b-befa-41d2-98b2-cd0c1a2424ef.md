## 课程要点

以下是历史课程的整理摘述，保留录制时的语境。数字、资格、政策、费用和页面步骤须在当前官方页面复核，不直接作为今天的操作结论。时间戳来自中英文音轨，音轨间可能不同；PDF 页码指原文件页码。

- API 服务：第三方应用访问销售数据的安全通道，包括销售伙伴 API (Selling Partner API / SP-API) 和传统服务网络商城服务 (Amazon MWS)。 **来源：Video 00:02:45.000；Video 00:02:52.000。**

- 亚马逊物流 (Fulfillment by Amazon)：即 亚马逊物流，涉及将库存运送至运营中心的货件 (shipment)。 **来源：Video 00:00:31.000；Video 00:03:07.000。**

- 卖家可以随时访问销售伙伴应用商店，网址为 sellercentral.amazon.com/sellingpartnerappstore。在主页上，卖家可以选择应用分类进行浏览，或者使用搜索框按名称查找特定应用。 **来源：Video 00:01:22.000；Video 00:01:25.000。**

- 单击某个应用程序的图标即可进入其详情页面，在其中可以查看功能介绍、联系信息和网络链接，以便快速访问和使用。 **来源：Video 00:01:43.000；Video 00:01:49.000；Video 00:01:53.000。**

- 在数据安全方面，应用商店中的某些应用程序直接与卖家平台集成，其他则是独立的，但所有应用程序都可以访问卖家在卖家平台中看到的相同销售数据。这些访问是通过 SP-API 或 Amazon MWS 进行保护的。此外，应用商店中的每个应用程序及其发布者（开发人员）都经过了亚马逊的审查和授权。 **来源：Video 00:02:19.000；Video 00:02:29.000；Video 00:02:38.000。**
