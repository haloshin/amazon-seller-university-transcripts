## 课程要点

以下是历史课程的整理摘述，保留录制时的语境。数字、资格、政策、费用和页面步骤须在当前官方页面复核，不直接作为今天的操作结论。时间戳来自中英文音轨，音轨间可能不同；PDF 页码指原文件页码。

- 本节课程主要解决卖家如何利用第三方应用程序来优化和自动执行定价策略的问题 [MODULE]。一些卖家完全依赖卖家平台（Seller Central）中的内置工具来发布商品、为商品定价并管理库存。还有一些卖家则通过第三方应用程序来改进其运营体验，以减少手动工作并保持商品在商城中的竞争地位。 **来源：Video 00:00:00.000；Video 00:01:51.880。**

- 销售伙伴应用商店（Selling Partner Appstore）：亚马逊提供的一个全面的已获批应用程序目录。该一站式商店包含经过审查的应用程序，可与销售运营体验集成。 **来源：Video 00:00:22.520；Video 00:00:48.880。**

- 第三方定价应用程序：通过安全 API 服务访问销售数据的专业化应用。 **来源：Video 00:01:30.880。**

- 亚马逊在销售伙伴应用商店中提供应用程序目录，卖家可访问 sellercentral.amazon.com/selling-partner-appstore 进行查看。 **来源：Video 00:00:36.560。**

- 要浏览应用商店，需从主页选择一个应用分类，或者使用搜索功能按名称查找特定应用程序。每个应用的详情页面都提供了有关其特点、功能和开发者联系方式的详细信息。 **来源：Video 00:00:55.880；Video 00:01:05.880。**
