## 课程要点

以下是历史课程的整理摘述，保留录制时的语境。数字、资格、政策、费用和页面步骤须在当前官方页面复核，不直接作为今天的操作结论。时间戳来自中英文音轨，音轨间可能不同；PDF 页码指原文件页码。

- 销售旺季（Sales peak season）：指消费者有不同购物需求的特定时期，包括公共假日（public holidays）、购物高度集中的节庆期（festive periods）以及 Amazon 指定的日期（如 Prime Day 和 Black Friday）。 **来源：PDF p.1；PDF p.3。**

- 旺季促销活动（Deal events）：在旺季享有更高曝光率的活动，包括 Lightning Deal (LD)、Deal of the Day (DOTD/Spotlight Deal) 和 7-Day Deal。 **来源：PDF p.4。**

- ASIN：Amazon Standard Identification Number 的缩写，是 Amazon 自动生成的唯一商品编号，无需卖家添加，一个 ASIN 代码对应一个 SKU。 **来源：PDF p.4。**

- 点击“advertisements”下的下拉菜单，选择“LD > create a new Deal”，活动选项卡（event tab）位于“date”列。 **来源：PDF p.4。**

- 点击“advertisements”下的下拉菜单，选择“LD > create a new Deal > select a product > arrange a Deal”，在创建促销时于“arrange a promotion”下选择相应活动。 **来源：PDF p.4。**
