## 课程要点

以下是历史课程的整理摘述，保留录制时的语境。数字、资格、政策、费用和页面步骤须在当前官方页面复核，不直接作为今天的操作结论。时间戳来自中英文音轨，音轨间可能不同；PDF 页码指原文件页码。

- 本模块旨在说明销售合作伙伴 (selling partner) 必须为特定商品提供电池测试总结 (Battery Test Summary)，以满足合规标准。 **来源：Video 00:00:30.000。**

- 所需文件：电池测试总结 (Battery Test Summary)，这种提供电池测试总结的要求一般称为提供 UN 38.3 报告。 **来源：Video 00:00:00.000。**

- 合规要求：为了遵守此标准，所有销售合作伙伴必须提供所有锂电池或锂电池组或由锂电池组供电的产品的测试总结。必须提供该总结，以确认锂电池符合 UN 38.3 测试要求。 **来源：Video 00:00:30.000；Video 00:00:49.000。**

- 这一机制的设立源于外部监管要求。从2020年1月1日开始，全球多个政府要求相关商品的制造商和分销商提供电池测试总结。平台执行此政策，是为了共同为锂电池和锂电池组维护一个安全合规的市场环境。 **来源：Video 00:00:00.000；Video 00:01:13.000。**

- 当你准备销售相关产品时，需判断商品是否属于锂电池/锂电池组或由其供电，并确认其生产日期是否在2003年6月30日之后。如果符合这两个条件，就必须准备 UN 38.3 报告。 **来源：Video 00:00:00.000；Video 00:00:30.000。**
