## 课程要点

以下是历史课程的整理摘述，保留录制时的语境。数字、资格、政策、费用和页面步骤须在当前官方页面复核，不直接作为今天的操作结论。时间戳来自中英文音轨，音轨间可能不同；PDF 页码指原文件页码。

- SSCC 箱子标签 (SSCC box labels)：即 serialized ship container code 标签，每个标签对应一个箱子 (box) 是唯一的。 **来源：Video 00:00:56.520；Video 00:01:04.440。**

- 承运人选项：包括 Amazon partnered carrier 或 seller managed carrier。 **来源：Video 00:00:49.240。**

- 从 AWD program page 点击 Send to AWD。通过选择 available SKUs 或选择 File Upload 来添加要发送的库存。接着选择 ship from address 和 preferred ship to region。 **来源：Video 00:00:08.520；Video 00:00:13.440；Video 00:00:20.040。**

- 选择 Amazon partnered carrier 或 seller managed carrier 作为 shipping method。 **来源：Video 00:00:49.240。**

- 无论选择哪种承运人，都必须打印 SSCC box labels。标签必须平整且无遮挡地贴在每个箱子的外面。 **来源：Video 00:00:56.520；Video 00:01:04.440。**
