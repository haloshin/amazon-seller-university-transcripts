## 课程要点

以下是历史课程的整理摘述，保留录制时的语境。数字、资格、政策、费用和页面步骤须在当前官方页面复核，不直接作为今天的操作结论。时间戳来自中英文音轨，音轨间可能不同；PDF 页码指原文件页码。

- 专业卖家（professional seller）：拥有此身份的卖家可使用单点登录（single sign-on）功能。 **来源：Video 00:00:43.000。**

- Amazon Solution Provider Network：提供第三方翻译等服务的网络。 **来源：Video 00:01:46.000。**

- 账户与导航：专业卖家关联账户后，可通过单点登录（single sign-on）用一个用户名和密码跨多个市场导航。你可以使用 marketplace switcher 查看同区域或跨区域的所有账户。 **来源：Video 00:00:43.000；Video 00:00:54.000。**

- Listing 与定价：使用 Build 工具添加报价后，可根据你设置的价格规则，自动将报价（例如从 Amazon.com）同步到 Amazon Japan。 **来源：Video 00:01:13.000。**

- 语言与翻译：商品详情页必须使用当地语言。Amazon 已将数百万个各品类的详情页从英语翻译为日语。如果你的商品目前不在日本市场，可以访问 Amazon.com/SPN 寻找 Amazon Solution Provider Network 上的第三方公司协助翻译。 **来源：Video 00:01:31.000；Video 00:01:46.000。**
