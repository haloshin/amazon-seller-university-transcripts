## 课程要点

以下是历史课程的整理摘述，保留录制时的语境。数字、资格、政策、费用和页面步骤须在当前官方页面复核，不直接作为今天的操作结论。时间戳来自中英文音轨，音轨间可能不同；PDF 页码指原文件页码。

- 本课程 主要解决品牌卖家如何识别、理解并通过 Brand Registry 的 Report a Violation 工具举报知识产权 (IP) 侵权行为的问题。它明确了该工具的适用范围、操作步骤以及与普通商店政策违规举报的区别，帮助品牌有效保护其版权、专利和商标。 **来源：PDF p.3。**

- Report a Violation 工具：专为管理 IP 问题设计，仅在 Brand Registry 中向具有 Rights Owner 或 Registered Agent 角色的用户开放。 **来源：PDF p.5。**

- Patent (专利)：为发明提供法律保护，分为 Utility (实用) 和 design (外观设计) 专利。 **来源：PDF p.4。**

- Store policy violation (商店政策违规)：与 IP 无关的违规行为，如不正确的变体、产品与描述不符、评论滥用等。这些必须通过 Seller Central Account Health 中的 Report abuse 表单提交。 **来源：PDF p.6。**

- Global search：在下拉菜单中选择发现侵权的特定国家商店。 **来源：PDF p.7。**
