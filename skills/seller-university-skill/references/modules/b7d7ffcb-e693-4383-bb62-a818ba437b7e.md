## 课程要点

以下是历史课程的整理摘述，保留录制时的语境。数字、资格、政策、费用和页面步骤须在当前官方页面复核，不直接作为今天的操作结论。时间戳来自中英文音轨，音轨间可能不同；PDF 页码指原文件页码。

- 多位置库存 (Multi-Location Inventory, MLI)：一项允许卖家共享基于位置的库存以提供准确送达日期的功能。 **来源：PDF p.1。**

- 卖家自配送 (Fulfilled by Merchant)：自行配送订单的卖家，是多位置库存功能的适用对象。 **来源：PDF p.1。**

- 配送设置自动化 (Shipping Settings Automation, SSA)：使用多位置库存功能必须启用的前置设置。 **来源：PDF p.1；PDF p.5。**

- 配送模板 (shipping template)：用于配置配送设置的模板，多位置库存允许在一个模板中设置多个位置。 **来源：PDF p.4。**

- 卖家需要设置一个或多个库存位置，可以通过 API 或在卖家平台（Seller Central）中手动设置。 **来源：PDF p.3。**
