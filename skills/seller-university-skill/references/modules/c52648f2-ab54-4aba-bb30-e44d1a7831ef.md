- 本节涉及的核心业务对象包括：通用商品（generic product）、商品详情页（product detail page）、库存文件模板（inventory file template）、Batch ID 以及 ASIN。 **来源：Video 00:00:11.500；Video 00:00:46.300。**

- 错误代码 5885 意味着你无法更改商品详情页。同时，该错误代码也意味着你无法在其他卖家的通用商品上添加报价，或者无法将商品详情页复制到其他商店。 **来源：Video 00:00:11.500。**

- 为了解决这个问题，官方推荐为无品牌通用商品（generic unbranded product）创建新的商品信息。 **来源：Video 00:00:22.700。**

- 如果你需要联系支持团队，请导航至 help，然后选择 get help and resources。接着，选择 adding a product，随后选择 received an error code or message，然后选择你的错误代码。 **来源：Video 00:00:29.300；Video 00:00:39.300；Video 00:00:59.800。**

- 如果你认为自己遵守了 Amazon 的政策，你可以联系销售伙伴支持。 **来源：Video 00:00:29.300。**
