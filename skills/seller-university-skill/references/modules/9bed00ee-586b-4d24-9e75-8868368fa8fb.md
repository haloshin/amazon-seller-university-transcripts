## 课程要点

以下是历史课程的整理摘述，保留录制时的语境。数字、资格、政策、费用和页面步骤须在当前官方页面复核，不直接作为今天的操作结论。时间戳来自中英文音轨，音轨间可能不同；PDF 页码指原文件页码。

- 亚马逊购买配送服务（Amazon Buy Shipping）是专门为处理自己商品配送事宜的卖家提供的一款工具。它的核心用途是帮助卖家自配送（Fulfillment by Merchant，简称 FBM）订单购买并打印货件标签（shipping label）。 **来源：Video 00:00:00.000；Video 00:01:11.000。**

- 该服务处理的业务对象是卖家自配送（FBM）的未发货订单。 **来源：Video 00:00:00.000；Video 00:00:46.000。**

- 根据英文版视频的补充说明，订单类型在处理时有不同的要求：Standard Orders 需要 automated handling time，而 Seller-fulfilled Prime 和 Premium Shipping Orders 仅仅需要按时发货即可。 **来源：Video 00:01:40.200；Video 00:01:46.100。**

- 要访问亚马逊购买配送服务，您可以将鼠标悬停在卖家平台（Seller Central）主菜单的订单选项卡上，选择管理订单，然后导航到未发货选项卡。此外，您也可以使用 Veeqo（英文版称为 VQuo）、配送 API 或其他多渠道合作商来访问该服务。 **来源：Video 00:00:35.000；Video 00:00:46.000；Video 00:00:25.000。**

- 在未发货选项卡中，选择您要发货的订单，然后选择购买配送服务。 **来源：Video 00:00:46.000。**
