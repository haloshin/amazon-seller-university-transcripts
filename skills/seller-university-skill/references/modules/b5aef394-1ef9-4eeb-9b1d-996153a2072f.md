## 课程要点

以下是历史课程的整理摘述，保留录制时的语境。数字、资格、政策、费用和页面步骤须在当前官方页面复核，不直接作为今天的操作结论。时间戳来自中英文音轨，音轨间可能不同；PDF 页码指原文件页码。

- 当你在自己的独立站（如 Shopify、WooCommerce）或其他电子商务渠道上销售商品时，如何解决仓储和发货问题？本节课程解决的核心问题就是：如何利用亚马逊的仓储和配送网络，为你非亚马逊渠道的订单进行拣货、包装和配送。 **来源：Video 00:00:06.000；Video 00:00:29.000；Video 00:00:00.000。**

- 多渠道配送（Multi-Channel Fulfillment / MCF）：亚马逊提供的一项服务，允许企业使用亚马逊的仓储和配送解决方案来处理自家网站或其他渠道的订单。 **来源：Video 00:00:06.000。**

- 配送订单（Fulfillment order）：当买家购买后，你在系统中创建的指令，用于通知亚马逊拣货、包装并配送。 **来源：Video 00:00:24.000；Video 00:00:29.000。**

- 保留订单（Hold order）：一种特殊的订单状态，用于为买家保留订购的商品，但不立即发货。 **来源：Video 00:03:09.000；Video 00:03:14.000。**

- API/集成：通过预先构建的集成（如 Shopify 和 WooCommerce）或自定义 API 自动创建订单，无需手动编码。 **来源：Video 00:00:45.000；Video 00:09:53.000；Video 00:10:01.000。**
