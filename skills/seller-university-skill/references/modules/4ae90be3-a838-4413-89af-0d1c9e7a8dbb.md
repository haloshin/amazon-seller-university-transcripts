## 课程要点

以下是历史课程的整理摘述，保留录制时的语境。数字、资格、政策、费用和页面步骤须在当前官方页面复核，不直接作为今天的操作结论。时间戳来自中英文音轨，音轨间可能不同；PDF 页码指原文件页码。

- 随着业务增长，手动多步任务会增加。Seller Assistant Workflows 可以自动化这些重复性流程，例如对买家消息进行分类并起草回复，或扫描目录以检测并解决商品信息质量问题。 **来源：PDF p.1。**

- 核心业务对象是 Seller Assistant Workflows。有两种开始方式：使用模板（Use a template）或从头开始（Start from scratch）。 **来源：PDF p.1；PDF p.2。**

- 打开 Seller Assistant 并要求它帮助自动化工作流。Seller Assistant 会提出问题以了解细节（如优先级、语气或参考资料）。随后，它会在 Builder 选项卡（Builder tab）中构建分步流程。激活后，工作流会按您设置的时间表运行，或在您手动触发时运行。 **来源：PDF p.3。**

- 当 Seller Assistant 注意到您运营中的重复模式时，它可能会建议使用工作流。本课程 未解释其他设计原因。 **来源：PDF p.1。**

- 监控账户状况或分析定价等常见任务可以使用预建模板。从头开始创建时，可以在 Seller Assistant Workflow 聊天面板（chat panel）中描述任务。在激活前，可以针对真实场景预览工作流以查看其表现。 **来源：PDF p.2；PDF p.3。**
