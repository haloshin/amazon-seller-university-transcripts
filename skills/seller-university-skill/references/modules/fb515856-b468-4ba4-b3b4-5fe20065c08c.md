## 课程要点

以下是历史课程的整理摘述，保留录制时的语境。数字、资格、政策、费用和页面步骤须在当前官方页面复核，不直接作为今天的操作结论。时间戳来自中英文音轨，音轨间可能不同；PDF 页码指原文件页码。

- 本节课程解决了卖家如何通过销售订阅盒 (subscription boxes) 来触达更多客户的问题。它详细说明了从提交申请、设置卖家账户、创建专属配送模板，到填写并提交 Listing 模板的完整官方流程。 **来源：Video 00:00:00.000；Video 00:01:42.800。**

- 订阅盒 (Subscription box)：这是单一类目下精选商品的集合，定期发送给客户。每个盒子包含由卖家组装的不同商品组合。 **来源：Video 00:00:00.000；Video 00:00:30.000。**

- 商品来源：卖家可以包含自有品牌商品、转售其他品牌的商品、Amazon 商店已有的商品，或者仅限订阅盒客户接收的新商品。 **来源：Video 00:00:59.800。**

- 变体 (Variations)：订阅盒可以创建变体，意味着同一订阅盒的不同版本可以发送给不同的客户。 **来源：Video 00:00:30.000。**

- 卖家可以随时申请销售订阅盒。访问 sell.amazon.com，悬停在 start 下拉菜单，点击 Amazon Selling Programs。在 Programs 页面向下滚动，找到 sell-down box，点击描述框中的链接，然后在下一页点击 apply now 按钮访问申请表。 **来源：Video 00:00:59.800；Video 00:01:28.800。**
