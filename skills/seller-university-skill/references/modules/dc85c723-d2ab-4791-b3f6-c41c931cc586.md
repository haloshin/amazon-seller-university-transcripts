- 亚马逊企业购 (Amazon Business) 提供了一系列功能，有助于优化企业对企业 (B2B) 销售。其中包括可以帮助您管理 B2B 运营并使其自动化的应用程序。这些应用程序的功能有助于定价和折扣，并提供销售机会和配送选项。 **来源：Video 00:00:05.000；Video 00:00:13.000；Video 00:00:20.000。**

- API：应用程序接口，是一组规则和协议，使不同的软件应用程序可以相互通信和交互。API 充当客户端和服务器之间的联系点。API 用于构建应用程序。 **来源：Video 00:00:37.000；Video 00:00:47.000；Video 00:01:03.000。**

- 私有应用程序：专为您的卖家账户构建的应用程序，因此只有您可以使用。 **来源：Video 00:01:44.000。**

- 作为卖家，您可以通过两种方式来使用 API：使用第三方集成商开发的公共应用程序，或使用销售伙伴 API (Selling Partner API) 构建自己的私有应用程序。 **来源：Video 00:01:20.000；Video 00:01:28.000。**

- 点击“添加新应用程序客户端”按钮，输入您的应用程序名称，并选择 SP API 作为 API 类型。 **来源：Video 00:02:01.000。**
