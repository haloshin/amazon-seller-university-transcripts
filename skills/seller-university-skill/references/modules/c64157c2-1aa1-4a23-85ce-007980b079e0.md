## 课程要点

以下是历史课程的整理摘述，保留录制时的语境。数字、资格、政策、费用和页面步骤须在当前官方页面复核，不直接作为今天的操作结论。时间戳来自中英文音轨，音轨间可能不同；PDF 页码指原文件页码。

- 亚马逊严禁销售假冒产品。为了防止客户收到假货，亚马逊推出了 Amazon Project Zero。该项目旨在结合亚马逊的技术与品牌的知识产权知识，将假货数量降至零。 **来源：Video 00:00:10.000；Video 00:00:00.000；Video 00:00:22.000。**

- 序列化服务 (serialization service)：一项可选服务，通过为每个商品应用唯一代码 (unique code) 来确认真实性。 **来源：Video 00:01:11.000；Video 00:01:21.000。**

- 加入项目并提供数据：品牌加入 Project Zero 后，需要提供商标 (trademarks)、徽标 (logos) 和其他关于品牌的关键数据点。 **来源：Video 00:00:39.000。**

- 系统自动扫描与拦截：自动保护功能每天扫描数十亿次尝试的商品信息更新 (listing updates)。系统会在疑似假货被添加到商店之前将其发现并移除。 **来源：Video 00:00:39.000。**

- 品牌自行移除：如果品牌发现了假冒商品信息 (counterfeit listing)，可以立即自行将其移除。此操作无需联系亚马逊。 **来源：Video 00:01:03.000。**
