## 课程要点

以下是历史课程的整理摘述，保留录制时的语境。数字、资格、政策、费用和页面步骤须在当前官方页面复核，不直接作为今天的操作结论。时间戳来自中英文音轨，音轨间可能不同；PDF 页码指原文件页码。

- 本模块主要解决卖家如何了解买家搜索行为的问题。通过 Search Query Performance (搜索查询绩效 / 搜索词表现) 报告，卖家可以了解买家在 Amazon store 中搜索其品牌的方式。这有助于卖家理解买家发现商品的途径，并突出显示趋势和机会，从而帮助扩展商品目录。 **来源：Video 00:00:24.000；Video 00:00:29.000。**

- 本模块的核心业务对象是 Search Query Performance (搜索查询绩效 / 搜索词表现) 报告，它是 Brand Analytics (品牌分析) 工具中的一份报告。 **来源：Video 00:00:15.000。**

- 要访问此报告，卖家必须是已在 Amazon Brand Registry (品牌注册) 中注册的品牌的内部卖家。符合条件的品牌可以享受额外的 brand selling benefits (品牌销售权益)，其中就包括该工具。 **来源：Video 00:00:37.000；Video 00:00:05.000。**

- 符合条件的卖家可以在 Seller Central (卖家平台) 的主菜单中选择“品牌”，然后点击“品牌分析”；或者点击“所有品牌权益”后找到品牌分析卡片。进入工具后，系统会直接跳转到该报告。 **来源：Video 00:00:48.000；Video 00:00:52.000；Video 00:01:12.000。**

- 报告会列出与品牌商品相关的买家查询，最热门的查询得分最高并显示在顶部，其余按降序排列，最多显示 1,000 个查询。默认情况下，报告显示前一周与品牌商品相关的所有查询。 **来源：Video 00:01:23.000；Video 00:01:30.000；Video 00:01:38.000。**
