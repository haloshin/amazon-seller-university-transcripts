## 课程要点

以下是历史课程的整理摘述，保留录制时的语境。数字、资格、政策、费用和页面步骤须在当前官方页面复核，不直接作为今天的操作结论。时间戳来自中英文音轨，音轨间可能不同；PDF 页码指原文件页码。

- Move Inventory 工作流允许卖家管理和分发亚马逊仓储和分拨（AWD）库存。当 FBA 库存不足时，卖家可以选择将 SKU 自动补货到 FBA。当自动补货不足以满足预期销售时，卖家可以请求将额外库存发送到 FBA。 **来源：Video 00:00:00.000；Video 00:00:31.260。**

- 亚马逊以外的地点：包括自有仓库、第三方仓库、批发商和分销商。 **来源：Video 00:00:31.260。**

- 要发起转移，请在 AWD 计划页面上选择 Move Inventory。 **来源：Video 00:00:31.260。**

- 如果在亚马逊网络内转移，请在 Distribution Type 下选择 FBA replenishment。 **来源：Video 00:00:31.260。**

- 如果转移到亚马逊以外的地点，请在 Move From Storage 页面的 Distribution Type 下选择 Off Amazon Distribution。选择此选项时，可点击 Manage Destinations 输入渠道和目的地信息，然后点击 Save。 **来源：Video 00:00:31.260；Video 00:01:01.160。**
