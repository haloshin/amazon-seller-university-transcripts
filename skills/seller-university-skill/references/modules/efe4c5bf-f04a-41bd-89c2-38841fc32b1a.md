## 课程要点

以下是历史课程的整理摘述，保留录制时的语境。数字、资格、政策、费用和页面步骤须在当前官方页面复核，不直接作为今天的操作结论。时间戳来自中英文音轨，音轨间可能不同；PDF 页码指原文件页码。

- 被禁止显示的商品信息（Suppressed listings）： 当提交的商品信息不符合 Amazon 要求时，商品可能会从买家的搜索结果中被禁止显示，或者在某些情况下，Amazon 不会将该商品信息添加到 Amazon 商店中。 **来源：PDF p.1。**

- 被阻止的商品信息（Blocked listings）： 在“管理所有库存（Manage All Inventory）”页面显示为“未售出 (已阻止)（Inactive (Blocked)）”状态的商品信息。 **来源：PDF p.2。**

- 匹配或冲突错误（Matching or conflicting errors）： 当你提供的商品 ID 或 SKU 被分配给 Amazon 商店中的其他商品，或者商品 ID 关联了 ASIN 但你输入的品牌、颜色或尺寸等属性与这些 ASIN 不匹配时触发的错误。 **来源：PDF p.5。**

- 要查看和管理这些问题，请打开 Seller Central 主菜单，将鼠标悬停在“库存（Inventory）”上，选择“管理所有库存（Manage All Inventory）”。 **来源：PDF p.1。**

- 通过更新数量或选择“补货（Restock）”来处理缺货的 SKU。 **来源：PDF p.1。**
