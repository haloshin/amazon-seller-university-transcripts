## 课程要点

以下是历史课程的整理摘述，保留录制时的语境。数字、资格、政策、费用和页面步骤须在当前官方页面复核，不直接作为今天的操作结论。时间戳来自中英文音轨，音轨间可能不同；PDF 页码指原文件页码。

- 上传文件功能 (upload file feature) 允许下载装箱单文件 (pack list file)。填写后将其上传回 Seller Central，以提供 box content information。 **来源：Video 00:00:00.000。**

- 此功能适用于任何类型的货件 (any type of shipment)。相关的操作均在 Seller Central 中进行。 **来源：Video 00:00:17.960；Video 00:00:00.000。**

- 对于每个箱子，输入每种商品的 number of units per product、expiration dates（如果适用），以及 box weight and dimensions。 **来源：Video 00:00:30.000。**

- 在选择模板格式时，如果喜欢使用该文件格式，可以改为下载 text tab delimited 版本的模板。 **来源：Video 00:00:55.800；Video 00:00:59.960。**

- 通过上传文件功能提供箱内物品信息，核心在于：输入箱子数量并下载模板，填写每个箱子的商品数量、保质期（如适用）、重量和尺寸，保存并上传回 Seller Central，且全程无需转换格式。 **来源：Video 00:00:20.880；Video 00:00:30.000；Video 00:00:47.800。**
