# 常用术语

以本仓库中文音轨与中文阅读标题为主要叫法，首次出现时可附英文；保留不同课程的语境，不机械替换所有同名词。

| 常用中文 | 英文 / 别名 | 使用说明 |
| --- | --- | --- |
| 卖家平台 | Seller Central | Amazon 卖家后台 |
| 亚马逊物流 | Fulfillment by Amazon / FBA | 与卖家自配送区分 |
| 卖家自配送 | Fulfilled by Merchant / FBM | 不等同于任何单一物流商 |
| 商品信息 | Listing | 与 ASIN、SKU、Offer 按语境区分 |
| 商品详情页 | Product detail page | 可聚合多个卖家的报价 |
| 推荐报价 | Featured Offer / Buy Box | 旧称常见“购物车”；不要承诺保证获得 |
| 商品推广 | Sponsored Products / SP | 与品牌推广的资格和预算设置区分 |
| 品牌推广 | Sponsored Brands / SB | 不把其选项套用到 SP |
| 展示型推广 | Sponsored Display / display ads | 按来源年代保留名称，当前产品名需核对 |
| 品牌注册 | Amazon Brand Registry | 不等于商标注册 |
| 品牌分析 | Brand Analytics | 报告资格与字段需按站点核对 |
| 会话次数 | Sessions | 与页面浏览量 Page views 区分 |
| 商品编号 | ASIN | Amazon 商品标识，不等于卖家 SKU |
| 库存编码 | SKU | 卖家管理库存用的编码 |
| 全球贸易项目代码 | GTIN | UPC 等属于商品编码体系 |

本表用于阅读和检索，不替代当前官方产品命名或资格说明。
