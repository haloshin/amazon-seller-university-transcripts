# 来源与范围

本版包含 356 个 Amazon 知识模块的课程定位与整理要点。来源快照为 2026-07-27，并非 Amazon 最新完整课程目录。每个要点附原视频时间戳或 PDF 页码；这是历史来源定位，不代表政策已经逐项更新。

270 个模块连接本项目已发布的中文转写/翻译阅读页，其余 86 个没有公开转写阅读页。官方逐课链接可能要求登录；链接状态随模块记录提供，未核实的链接明确标注。

公开 Skill 不包含视频、PDF 文件、原始全文素材、知识卡图集、课程题库、内部发布规划或私有服务配置。不依赖作者的服务器或模型通道；检索在本地运行，回答由用户自己的 Agent 完成。

发布整理时仅保留逐条有来源锚点的课程要点，未纳入无行内引用的扩写、机械角色模板和题目。修正了批量商品模板课程中“最多 500 个商品编码”的文字错误。锚点解析与结构检查不等于逐句人工审定或最新政策核验。
