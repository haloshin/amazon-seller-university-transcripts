# 动态信息核对

课程快照用于学习机制，不能直接代表今天的政策。费用、资格、促销窗口、预算、竞价、库存、利润、账户健康、时效、页面字段和工具可用性都可能改变。

1. 明确 marketplace、适用的账户/商品、日期和用户要采取的动作。
2. 优先核对当前 Amazon 官方帮助页或用户授权提供的后台页面；宿主没有联网能力时明确说明，给出需要核对的页面名称和项目，不编造查询结果。
3. 回答中记录实际读取的 URL、核对日期、适用对象。仅有历史课程链接时不得标“今日已核实”。
4. 资料冲突时分别说明课程录制时口径与当前官方口径；当前数值仍不明确就保留待核实，不进行资金、账户或库存操作。

特别注意：Sponsored Products 与 Sponsored Brands 的预算选项不能混用；推荐报价不是单纯的最低价保证；销售额、广告归因销售额、利润不能互相替代。历史课程中的建议、例子和平台硬性要求也要区分。
