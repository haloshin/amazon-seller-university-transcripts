# Generic Product Policy: Resolve error code 5882

欢迎来到此卖家大学模块。今天,我们将讨论无品牌商品政策错误代码5882以及如何解决此问题。如果您收到错误代码5882,则可能正在尝试创建被标记为侵犯品牌知识产权IP的无品牌商品信息。
在您的无品牌商品信息中,使用其他品牌的IP,或将品牌列为无品牌商品,都违反了亚马逊的商品信息政策。
为确保合规性,请先查看亚马逊品牌名称政策和亚马逊知识产权政策。
如果您认为自己遵循了所有政策,但仍然遇到此错误代码,请点击"帮助",
然后点击"获取帮助和资源",选择“我的问题未列出”,
然后输入"我想创建无品牌 ASIN 且收到了错误 5882"。
销售伙伴支持成员将联系您以提供帮助。
请记住,维护亚马逊商城的诚信度对于您成功成为销售伙伴至关重要。
