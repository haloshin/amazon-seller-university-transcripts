# 本轮修订记录

|---|---|---|
| Build | BIL | Build International Listings 的缩写 BIL，Build/Bill 均为同音误识 |
| Build | BIL | 同段工具简称 BIL |
| build | BIL | 同段 BIL connection 指工具连接 |
| Cell | Sell | 固定导航 Sell Globally，纠正 Cell |
| Cell | Sell | 固定导航 Sell Globally，纠正 Cell |
