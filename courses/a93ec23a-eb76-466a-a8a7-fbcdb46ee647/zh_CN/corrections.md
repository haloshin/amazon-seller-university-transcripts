# 本轮修订记录

逐项记录相对旧转写稿的修改。详细原片证据保留在本地校准审计中。

| 修改前 | 修改后 | 原因 |
|---|---|---|
| 的。 ⏎ 商标注册 |  | 结合本句语义与同课/术语证据，修正明确同音错字或恢复新识别支持的漏词，不改写课程内容。 |
| 政府认识商标的知识商标的知识亚马逊和法律保护仍应国家或地区而已 | 政府认证商标的知识产权和法律保护仍因国家或地区而异 | 新ASR明确恢复知识产权；完整句修重复、因/异同音，保留国家地区范围。 |
| 带处理 | 待处理 | 待处理商标申请/注册的同音误识别，保留申请及注册两种原有表述。 |
| 以或认可 | 已获认可 | 原片248秒帮助页标题明确“已获认可的商标局的注册指南”。 |
| 有效地已注册商标 | 有效的已注册商标 | 的/地同音字，修正定语书写，不更改商标要求。 |
| 分布操作指南 | 分步操作指南 | 同音误识别；全文语义及前后用词明确，保持原句内容。 |
