# Generate return reports

欢迎观看本期关于退货报告的培训视频。
如果买家喜欢他们购买的商品,这当然很棒,但有时候,买家打开包装之后,却发现商品并不适合他们。
发生这种情况时,他们可能会决定退货。跟踪退货商品以及退货时间,是业务流程的一个重要环节。
您可以使用亚马逊的退货报告功能,监控买家退货情况,并生成记录。
要访问您的退货报告,请打开卖家平台Seller Central主菜单,将鼠标悬停在报告Reports上,然后点击退货报告Return Reports。
在退货报告Return Reports页面上,您可以通过按需生成报告或安排定期生成报告来跟踪您的退货历史记录。
第一个选项是生成一次性报告。为此,首先,
选择是要生成所有退货报告,还是只想要生成Prime退货报告,然后选择您希望报告涵盖的时间段。
如果您选择确切日期 ,Exact Date,则需要选择您希望报告涵盖的日期范围。
做出选择后,选择请求,Request。
请求报告后,系统会通知您报告正在处理中。
您的请求将显示在“已生成报告”,Generated Reports 下方。
创建报告所需的时间,将取决于相应报告日期范围内的退货数量。
选择刷新/refresh以检查报告的状态。
如果在此时间段有退货,您会收到指向XML文件和TSV文件的链接。
XML文件是可扩展标记语言文件,而TSV文件是制表符分隔值文件。
大多数商业电子表格应用程序都可以打开TSV文件。
如果要安排定期生成报告,请选择安排生成报告:Schedule Report Generation。
在这里,您可以生成三种不同类型的报告:
豁免报告、所有退货报告,以及Prime退货报告。
选择您希望接收任何报告选项的频率,然后选择该选项旁边的安排:Schedule。
如果已安排报告,您将会看到生成下一份报告的日期,以及重新安排或取消安排报告的选项。
重新安排报告会更改报告时间,而取消安排报告会停止自动生成报告。
创建预定报告后,您可以在《退货报告》、《Return Reports》页面的已生成报告。
《Generated Reports》下找到该报告。
打开《退货报告》时,您会看到符合所选条件的每次退货的相关信息。
您可以查看订单编号、订单日期,请求退货的日期和退货状态。
接下来几列:提供有关退货标签及其配送方式的信息。
有关退货标签的更多信息,请在卖家平台Seller Central中搜索预付费退货和不退货解决方案。
Prepaid Returns and Returnless Resolutions。
您还可以找到相关信息,了解退货是亚马逊商城交易保障索赔的结果,还是Prime订单。
查看有关商品本身、退货数量和退货原因的信息。
这些信息对于帮助您监控库存非常重要。
如果您发现同一商品的多个订单因相同的原因退货,请检查商品和商品信息,确保没有任何问题。
您也许能够提前发现这个问题,以免影响您的账户状况。
接下来几列:显示退货是否与SAFE-T索赔有关。
SAFE-T:代表卖家电子商务交易保障（Seller Assurance for E-Commerce Transactions）。
如果亚马逊代表卖家处理退货,卖家可能会提出SAFE-T索赔,但需满足表明卖家不对退货承担任何责任的某些条件。
要了解有关SAFE-T索赔的更多信息,
请在卖家平台Seller Central搜索框中搜索SAFE-T索赔
SAFE-T Claims。
在最后一列中,您可以看到每次退货退还给买家的金额。
如果您使用亚马逊物流
FBA销售商品,还有其他专门针对FBA卖家的报告
要访问这些报告,请点击退货报告
Return Reports页面顶部附近的查看FBA报告
View FBA Reports

感谢观看,祝您销售愉快。
