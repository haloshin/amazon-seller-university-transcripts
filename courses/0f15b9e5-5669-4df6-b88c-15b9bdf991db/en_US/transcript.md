# How to use keyword match types

Keyword match types help you control where your ads appear.
 There are three ways to set them in your campaigns.
 First, you can use Amazon's suggested keywords.
 By default, each one includes the three match types to choose from,
 "Broad", "Phrase", and "Exact". Add whichever match types you'd like to your targeting.
 If you're entering your own list of keywords, make sure the match types you want to include
 are checked off at the top. Lastly, you can bulk upload a list of keywords.
 In this case, our template includes a column for the match type.
