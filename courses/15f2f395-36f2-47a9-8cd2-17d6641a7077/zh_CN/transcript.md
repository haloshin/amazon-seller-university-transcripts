# Set ASIN-specific handling time

欢迎观看本期关于为卖家自配送ASIN单独设置备货时间的培训视频。
在本视频中,我们将介绍如何为ASIN单独设置备货时间。
该功能一般适用于需要特别处理或需要进行与目录中其他商品不同准备工作的ASIN。
该功能可以帮助您管理订单处理渠道,
并维持健康的账户状况/Account Health。
亚马逊商店中的报价都会有买家配送承诺,
该信息可以让买家看到预计收货时间。
买家很少愿意接受过长的发货时间,
所以默认备货时间较短的商品会更具吸引力。
同时,按承诺的时间按时交货非常重要,
因为延迟交货可能会影响账户状况/Account Health。
比方说,您想将默认备货时间设置为一天,
但是您目录中的某些ASIN很难在一天之内完成备货。
这时,您就可以采用为ASIN单独设置备货时间的解决方案。
为ASIN单独设置的备货时间是正常处理时间的例外设置。
如果某件商品可以比默认时间更快地发货,
或者需要比平时更长的时间来发货,
您就可以为这些ASIN单独设置备货时间,
以遵守配送承诺。
比如,您设置默认备货时间为一天,
但一件特别精细的商品在发货前需要进行特殊准备,
您就可以为该ASIN单独设置两天的备货时间,
且该设置不会影响其他商品的正常配送。
由于每个ASIN的特定备货时间都需要单独设置,
因此,您需要从管理库存、Manage Inventory界面进行该操作。
您可通过选择左上角带有三条水平线的按钮,
打开卖家平台主菜单,
前往库存,Inventory,
然后选择管理库存,Manage Inventory。
之后,在库存中需要单独设置备货时间的ASIN旁,
选中复选框,
然后选择该行最右端的编辑,Edit按钮。
由于屏幕大小存在差异,
您可能需要向右滚动才能找到该按钮。
在该ASIN的编辑详情界面上,选择“报价”（Offer）选项卡,然后向下滚动到处理时间,Handling Time。
在此处,您可按工作日来设置备货时间。
假设在此处输入 2,
那么在收到该ASIN的订单后,您将有两个工作日的时间来配送商品,
并在卖家平台确认该货件。
虽然一般来说,您需要逐个为ASIN单独设置备货时间,
但如果熟悉库存加载程序,您也可以通过上传文件来批量设置备货时间。
在卖家平台中搜索修改备货时间,Modify Handling Time,便可了解有关此选项的更多信息。
备货时间是买家配送承诺和账户状况,Account Health的关键部分。
因此,请务必为目录中的每件商品提供准确的备货时间。
如果您的大部分商品都可以快速送出,可将默认备货时间设置为一天,
然后为需要更多准备的ASIN设置更长备货时间。
这样就能尽可能地缩短配送时间,维持健康的账户状况。
