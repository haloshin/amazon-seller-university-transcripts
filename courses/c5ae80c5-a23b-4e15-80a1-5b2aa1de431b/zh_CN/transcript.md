# Brand Analytics: Search Catalog Performance report

欢迎参加我们关于品牌分析全系商品搜索表现报告的培训,已在亚马逊品牌注册中注册的品牌,可以享受一系列额外的销售权益,包括卖家平台中的品牌分析工具。
在本视频中,我们将了解品牌分析中提供的其中一个报告的特性和功能。
该报告就是搜索目录表现,该报告使品牌可以深入了解买家在店铺中进行搜索后,如何与商品互动。
它有助于品牌确定其商品的买家流失点,或者找出曝光率和销售转换率方面的差距。
如果您是已在品牌注册中注册的品牌的内部卖家,便可访问搜索目录表现报告,以及品牌分析工具中的其他报告。
操作非常简单,只需在卖家平台的主菜单中选择品牌、brands,然后点击品牌分析、brand analytics,或者点击所有品牌权益, All Brand Benefits.
然后找到品牌分析,brand analytics卡,有关访问品牌分析和其他品牌注册工具的更多信息。
请观看卖家大学中关于请求获得或管理品牌销售权益的模块。
访问品牌分析工具后,您可以从屏幕顶部的报告列表中选择搜索目录表现。
Search Catalog Performance
该报告按商品名称,列出了您品牌下的各种商品。
在第二列中,您将看到品牌ASIN和类别。
然后,您将看到一系列指标。
这些指标代表了整个购买漏斗中的买家活动。
展示量,Impressions,是指商品出现在搜索结果页面上的次数,包括普通商品和商品推广。
此数字不包括小部件中出现的商品,例如备受好评商品或新品。
在展示量旁边,您会看到还一起显示了商品的中价。
例如,属于您品牌的一款太阳镜,在搜索结果页面上出现了100次。
其中价为50美元。
总点击量,Clicks,是指商品出现在搜索结果页面后,买家点击商品的次数。
在点击量旁边,您将看到商品的点击率,其买家点击商品的次数占展示量的百分比。
例如,如果您的太阳镜在展示100次后被点击了50次,那么其点击率将为50。
加购次数,Cart Adds,是指买家搜索,点击商品。
然后使用商品详情页面上的加入购物车,Add to Cart按钮,将其放入购物车供日后购买的次数。
例如,在获得50次点击后,您的太阳镜被加入购物车的次数可能为25次。
购买次数,Purchases,是指买家搜索,点击商品,然后订购商品的次数。
该指标包括您的销售额,以及其他发布该商品的卖家的销售额。
在购买次数旁边,您会看到该商品的相关销售额以及转化率。
转化率是指买家点击商品后进行购买的次数,占点击次数的百分比。
例如,买家可能购买了您的10副太阳镜,总销售额为525美元。
在这种情况下,转化率将为20%。
因为该商品在搜索结果页面上获得50次点击后,有10副被买家购买。
请注意,全系商品搜索表现报告中的指标是特定于搜索的,并且可能与其他亚马逊报告和控制面板中提供的指标不相符。
这是因为每个报告和控制面板对买家活动的定义和呈现方式各有不同。
您首次访问全系商品搜索表现报告时,它将默认显示前一周您所有品牌的商品。
您可以使用顶部的下拉菜单,查看特定的时间段。
这样做时请注意,品牌分析中的数据可用时效通常为72小时。
选择时间段后,点击应用,Apply按钮刷新报告。
您也可以使用筛选条件,将报告范围缩小到特定品牌或商品系列。
点击显示筛选条件,Show filters。
然后使用下拉菜单选择品牌。
或者,在搜索框中输入最多100个ASIN,并用空格或逗号分隔。
点击细化结果,Refine Results按钮刷新报告。
如果您想在搜索目录表现报告中添加或移出列,请点击右侧的自定义列,Customize Columns,然后选中或取消选中弹出窗口中的复选框。
点击保存,Save按钮,返回到更新后的报告。
若要下载报告的副本,请点击生成下载项,Generate Download按钮。
然后,在弹出窗口中,选择简洁视图,Simple View,下载您在屏幕上看到的报告,或者选择综合视图。
Comprehensive View,下载包含所有相关列的报告。
点击生成下载项,Generate Download按钮开始下载。
您可以通过访问下载管理器,Download Manager,查看下载进度。
最后,如果您想了解有关如何计算特定指标的更多信息,请点击指标术语表,Metrics Glossary,以查看一组全面的定义。
在指标术语表,Metrics Glossary页面上,您可以展开每个部分,以查看更多详细信息。
我们鼓励品牌使用搜索目录表现报告的所有特性和功能,以深入了解它们在店铺中取得的绩效。
使用点击阶段的流失点,确定哪些商品详情页面可能需要更新,
使用其他指标制定广告策略,以帮助您的商品吸引更多流量。
我们对全系商品搜索表现报告的概述到此结束。
如果您想了解其他品牌分析报告的分步说明,请观看卖家大学中的相应模块系列。
感谢观看,祝您销售愉快。
