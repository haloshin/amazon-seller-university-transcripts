欢迎参加我们关于如何在卖家平台上生成库存报告的培训。
所有拥有专业销售账户的卖家都可以访问许多有关他们店铺中的商品的库存报告。
在本视频中,我们将向您展示如何访问和自定义这些报告。
您可以使用库存报告,查看您当前的数量水平、SKU级别的绩效。
在卖家搜索结果中被禁止显示、不可售或存在质量警告的 SKU。
要访问您的库存报告,请打开卖家平台主菜单。
将鼠标悬停在“报告”（Reports）上。
然后选择库存报告、Inventory Reports。
使用选择报告类型。
Select Report Type 下拉菜单,选择要生成的报告。
在每种类型的下方,您会看到选定报告中所包含内容的一览。
选择报告后,单击自定义此报告的列。
Customize the columns for this report。
系统将显示一个新页面,并显示其他指标。
从可用属性、Available Attributes 中选择一个指标。
然后单击添加、Add,以使用该指标自定义报告。
要移除该指标,只需从选定属性、Selected Attributes 中选择该指标。
然后单击移除、Remove。
准备好保存自定义报告设置后,选择保存、Save,
或者单击重置、Reset,以恢复默认设置。
然后返回库存报告、Inventory Reports 页面,
并选择请求报告、Request Report 以生成您的自定义报告。
如果您要在不进行任何更改的情况下请求报告,
只需在选择报告类型后,单击请求报告、Request Report 即可。
系统通常会在45分钟内生成报告。
因此,请记住,您的库存可能会在此时间间隔内发生变化。
使用报告抽查您的库存并确定趋势,
然后将它们与您自己的记录进行比较。
您可以在库存报告、Inventory Reports 页面的报告状态、
Report Status 和下载、Download 列中找到您的报告。
生成报告后,报告状态、Report Status 列会显示就绪、Ready。
要下载报告,请单击报告旁边的下载、Download 链接。
在卖家平台上搜索库存报告、Inventory Report。
找到每个报告中包含的指标的示例。
您还可以通过观看卖家大学中的管理库存视频。
找到有关如何管理和更新库存的更多信息。
