# Payments Dashboard overview

"卖家平台"中的付款控制面板详细展示了您获得付款的时间和金额一览。要查看付款报告,请将鼠标悬停在付款上,然后点击付款。此时,您将进入付款控制面板。在这里,您可以查看近期的结算情况。您可以查看您的总余额、可用资金和近期付款情况。在交易一览选项卡中,您可以查看交易状态和延期原因,并查看任何延期交易的付款发放日期。点击下载按钮可下载表格中显示的前600笔交易。在所有结算选项卡中,您可以下载各个结算周期的付款报告。如果您有账户级别的预留金额,它们将显示在其他列中。在付款选项卡中,您可以查看各个结算周期的付款状态。最后,报告库选项卡汇总了与您在亚马逊商城的付款相关的所有报告。在此选项卡中,您可以按日期范围请求报告,追踪付款报告状态并为报告添加标签。如果您没有为报告添加标签,我们将提供一个默认标签。使用标签便于对报告进行排序。
您还可以安排未来出具报告的时间。如果您选择当天或未来的某个日期,报告将在您选择的结束日期后24小时内准备就绪。
如果您在查看报告状态时发现其状态显示为失败,请等待24小时后再次请求报告。
您也可以尝试使用较短的日期范围,分多次发起请求。
要了解有关接收付款的更多信息,请在卖家平台中搜索付款常见问题。
