# 本轮修订记录

逐项记录相对旧转写稿的修改。详细原片证据保留在本地校准审计中。

| 修改前 | 修改后 | 原因 |
|---|---|---|
| Do | Did | Did you know?常用引介问句，第二识别支持过去助动词。 |
|  | I'll show you the results. ⏎  | 第三轮独立small明确补出I'll show you the results，按该证据恢复，避免采用第二轮Let me的改述。 补句末标点以免插入段与后句粘连。 |
| Pallavi Pandey | Pallavi Pande | 25秒原视频字幕确认姓名拼写Pallavi Pande。 |
| Detox | Dtocs | 25秒原视频字幕和产品logo均为Dtocs；两轮ASR误识别品牌。 |
| bolts | bowls | 33秒原字幕明确bowls，餐具语境不是bolts。 |
