# FBA dashboard overview

欢迎观看我们的亚马逊物流控制面板概述视频。
亚马逊物流控制面板可帮助您管理和发展亚马逊物流业务,所有操作都在一个页面上进行。
在本视频中,我们将介绍使用亚马逊物流控制面板的主要好处,以及如何访问该页面及其功能。
要找到亚马逊物流控制面板,请打开卖家平台主菜单,
将鼠标指针悬停在库存、Inventory上,然后点击控制面板、Dashboard。
您将到达亚马逊物流控制面板FBA Dashboard的页面。
在这里,可以找到与亚马逊物流相关的所有内容,包括有关您的库存、货件、销售额和绩效的信息。
您可以使用此控制面板,查看亚马逊物流指标,并利用我们的建议
来帮助发展您的业务。
在该页面顶部,您可以找到亚马逊物流导航菜单。
库存Inventory菜单,包含与亚马逊物流库存相关的链接。
下一个菜单,货件、Shipments,包含诸如管理货件、Manage Shipments之类的链接,可帮助您了解和管理库存配送。
在机会,Opportunities页面上,我们会分析您的目录,并建议在亚马逊物流和亚马逊物流轻小商品计划中注册哪些 ASIN。
亚马逊物流轻小商品计划有助于降低价格低于10美元的轻小库存的订单配送费用。
我们的建议还汇总在亚马逊物流控制面板的机会,Opportunities卡上。
最后一个菜单选项是分析,Analytics。
它可帮助您直观地查看销售数据。
您可以使用诸如日期范围和SKU等不同的筛选条件,来分析销售绩效。
亚马逊物流控制面板的第一部分,包含您的关键绩效指标。
已订购的商品销售额,Sales Ordered,已订购商品数量,Units Ordered,和订单,Orders。
这三张卡汇总了您的销售额,并显示了年同比情况。
您也可以筛选这些指标的日期。
点击已订购商品的销售额,Sales Ordered卡上方的箭头,可显示相关下拉菜单。
然后,选择日期范围,或通过选择自定义,Custom,来设置自定义范围。
在下面的计划库存,Plan Inventory卡中,您可以找到库存绩效指数,Inventory Performance Index,简称IPI分数。
该分数基于您在推动销售和管理现有库存方面的表现。
密切关注您的IPI分数非常重要,因为低于阈值,可能会限制您的仓储量。
如果您点击查看详情,View Details,则会转到IPI页面。
在计划库存,Plan Inventory卡中,在右侧显示了主要影响因素,Top Influencing Factors,并且重点介绍了您可以采取哪些措施来提高IPI分数。
将鼠标指针悬停在每个链接上,可了解更多信息。
货件Shipments卡提供了有关您在过去120天内的货件状态的数据。
它将货件总数分为四个类别。
正在处理的货件,Working Shipments,在途货件,In Transit Shipments,在运营中心,At Fulfillment Center,和已关闭的货件,Closed Shipments。
如果您要查看更多详情,请点击查看所有货件,View All Shipments。
您将转至货件处理进度,Shipping Queue页面。
此处还会标记货件问题,例如货件缺少追踪编码。
库龄Inventory Age卡有助于您防止产生长期仓储费。
它会显示您的库存中有多少商品在特定的库龄范围内。
这些范围包括0~180天、181~270天、271~365天和超过365天。
这可以帮助您清晰看到有多少商品存在因超过阈值而产生长期仓储费的风险。
最后,优化库存Optimize Inventory卡会显示我们建议您因供应不足而需补货,
或因冗余库存而需管理的SKU。
您还将看到哪些商品符合诸如创建奥特莱斯限时促销、
创建移除订单、通过广告宣传商品信息和补货等推荐操作的条件。
点击链接,可导航到亚马逊物流库存页面的筛选后视图。
您可以在其中找到要优化的特定库存商品。
我们对亚马逊物流控制面板的概述到此结束。
感谢观看,祝您销售愉快。
