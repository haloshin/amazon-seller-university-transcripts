# 本轮修订记录

逐项记录相对旧转写稿的修改。详细原片证据保留在本地校准审计中。

| 修改前 | 修改后 | 原因 |
|---|---|---|
| CEA | CA | 同课英文明确为 add CA or MX，确认 CEA 是 CA 的识别错误。 |
| amazon.ca.sell | amazon.ca/sell | 同课英文列出 amazon.ca/sell，修正网址分隔符。 |
| sell.amazon.com.mx | sell.amazon.com/mx | 同课英文逐字网址为 sell.amazon.com/mx；不以国家站域名猜测。 |
| 货币也应商店而已 | 货币也因商店而异 | 同课英文 currency also differs between stores 支持。 |
| 比锁 | 比索 | 墨西哥货币名称 pesos 同课英文明确支持。 |
| 该义务 | 该业务 | 同课在说明跨国床垫销售业务 business。 |
| 国际义务 | 国际业务 | 同课英文 international business。 |
| 所收商品 | 所售商品 | 本段销售分类要求语境，所售为同音更正。 |
