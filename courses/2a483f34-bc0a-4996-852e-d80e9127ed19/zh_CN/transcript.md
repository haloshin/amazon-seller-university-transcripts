# Generic Product Policy: Resolve error code 5886/7

欢迎来到卖家大学关于无品牌商品政策错误代码5886和5887的模块。本视频将解释这些错误代码的含义,以及如何解决这些错误代码,以成功在亚马逊上架您的商品。错误代码5886和5887,表示您正在尝试更改您无权修改的商品详情页面。
如果您尝试向其他卖家的无品牌商品添加报价,或者将商品详情页面复制到未获批准的商城,则可能会发生这种情况。您无法直接编辑或更改属于其他卖家的无品牌商品详情页面。如果您想销售无品牌商品,则需要创建自己的新商品信息。您可以使用亚马逊卖家平台上的添加新商品
工具进行此操作。您可以使用此工具,为要销售的商品创建新的商品详情页面。
让我们来看一个例子。假设您想出售一款无品牌手机壳,您不能简单地复制现有手机壳商品的详情页面,而是需要为自己销售的手机壳创建新的商品详情页面。
此操作涉及在添加新商品工作流程中,提供所有必须的商品信息、图片和相关详情。
创建自己的新商品后,您将能够发布和销售您的无品牌商品,而不会出现5886和5887错误代码。
亚马逊无品牌商品政策和相关错误代码的更多信息,见无品牌商品政策帮助页面。
感谢观看,祝您销售愉快!
