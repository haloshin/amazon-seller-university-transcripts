# Get recommendations for case packs

欢迎参加本期"关于获取新整箱包装和现有整箱包装建议"的培训。
亚马逊支持三种包装配置类型:单件商品、整箱包装和托盘。
本培训视频将重点介绍整箱包装。
这种包装配置类型在大销量、企业对企业、B2B业务中很常见,
可以帮助吸引亚马逊企业买家。
下面将演示
卖家如何使用整箱装商品的销售机会
Case Pack Product Opportunities 工具
来获取建议。
要使用整箱装商品的销售机会
Case Pack Product Opportunities 工具
您需要满足以下两项基本要求。
您是专业卖家。
您是在亚马逊品牌注册
Amazon Brand Registry 中
已注册品牌的内部卖家或授权经销商。
要在卖家平台中访问该工具,请打开主菜单。
将鼠标悬停在B2B上,然后点击B2B平台、B2B Central。
在下一页上,点击装箱推荐、Case Pack Recommendations。
您会看到对应于两种建议的选项卡。
第一部分,添加新的整箱装商品。
Add New Case Pack 。
显示您作为目前单件商品销售的商品。
您或其他卖家尚未将这些商品以整箱包装形式在店铺中上架。
它们属于已在品牌注册、Brand Registry 中注册的品牌。
您是该品牌的内部卖家或授权经销商。
该工具的添加新的整箱装商品。
Add New Case Pack 部分中所列的商品。
根据您从亚马逊企业买家收到的包含多件商品的订单的数量进行排名。
包含多件商品的订单可能表明。
可能需要以整箱包装出售商品。
每种商品的旁边,
会列出您在去年收到的包含五件或更多商品的订单的数量。
还会列出与这些订单相关的销售额,
并提供整箱包装的建议尺寸。
亚马逊根据亚马逊企业买家最常从您那里购买的商品数量建议整箱包装尺寸。
如果您决定根据建议创建新的整箱包装商品信息,
您有两种选择。
您可以点击"创建整箱包装",
"Create Case Pack"按钮,
为您的整箱包装创建独立的商品信息,
或者,您可以点击"注册亚马逊批量服务",
"Enroll in Amazon Bulk Services",
来建立包装层次结构。
然后创建既包含整箱包装,
又包含单件商品的合并商品信息。
亚马逊建议您采用第二种选择。
因为创建合并商品信息,
能够让买家更轻松地查找、
比较和购买不同数量和包装配置的商品。
利用合并商品信息,
还可以在亚马逊批量服务"ABS"中自动注册整箱包装。
该程序通过增强的工具,
支持批量B2B销售,
带来了额外的收益,
包括降低符合条件的整箱包装的销售佣金。
如果您决定创建合并商品信息,
请点击"注册亚马逊批量服务",
Enroll in Amazon Bulk Services转到"创建包装层次结构",
"Creating a Package Hierarchy"帮助页面。
本页将逐步介绍,
如何为您的整箱包装,
以及您要在整箱包装和商品的单件商品之间
建立的包装层次结构,
生成和填写库存文件。
该页面还说明了如何将您的库存文件
上传到卖家平台,
以创建合并商品信息。
除了查看该帮助页面之外,
亚马逊还建议您观看卖家大学视频。
亚马逊批量服务,
为整箱包装和托盘创建合并商品信息。
如果您决定为您的整箱包装创建独立的商品信息,
而不是合并商品信息,
请点击"创建整箱包装",
"Create Case Pack"按钮。
系统将跳转到商品信息页面。
在此页面中,
您可以使用亚马逊的标准商品信息流程,
为您的整箱包装输入和选择内容。
整箱包装商品机会。
Case Pack Product Opportunities工具中的第二部分,
是添加新报价。
Add New Offers。
该部分显示,
其他卖家已在店铺中上架的整箱包装,
与上一个选项卡上的单个商品一样。
这些整箱包装,
属于已在品牌注册,
Brand Registry 中注册的品牌。
而您是该品牌的内部卖家或授权经销商。
所列的整箱包装,
根据亚马逊企业买家,
在去年对这些整箱包装的下单总数进行排名。
每种整箱包装的旁边都提供了建议价格。
亚马逊根据整箱包装的现行B2B推荐报价建议价格。
如果您没有看到建议价格,
则表示相应整箱包装目前没有推荐报价。
如果您决定将报价与现有的整箱包装商品信息相匹配,
请点击添加新报价,
Add an Offer按钮。
系统随即转到报价,
Offer页面。
在此页面中,
您可以使用亚马逊的标准流程,
输入您的定价和数量信息。
或者,
如果您想要添加报价,

Amazon Bulk Services,
